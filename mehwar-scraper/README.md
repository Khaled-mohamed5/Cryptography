# تجميع طلبات الأدبي (الاسم + الرقم)

سكريبتات بتجمع أسماء وأرقام الطلبات من صفحة الأدمن بتاعتك
`centerelmehwar.com/admin/Emp.aspx` وتطلعها في ملف **CSV** يفتح على Excel على طول.

بتشتغل من خلال حسابك انت اللي مسجّل بيه — مفيش أي تخطي للوجين.

| | `browser-console.js` | `collect.py` |
|---|---|---|
| المتصفح | مطلوب تكون فاتح ومسجّل دخول | مش مطلوب |
| تثبيت حاجة | ❌ ولا حاجة | Python + مكتبتين |
| الاستخدام | مرة ومرتين، أسرع حاجة | تشغيل متكرر / أتمتة |

---

## الطريقة الأولى: من المتصفح (الأسرع — مفيش تثبيت)

1. افتح الموقع وسجّل دخول، وادخل على صفحة **Emp.aspx**.
2. اضغط **F12** → تبويب **Console**.
3. لو ظهرت رسالة تحذير حمرا، اكتب `allow pasting` واضغط Enter (كروم بيطلبها أول مرة).
4. افتح ملف `browser-console.js`، انسخه **كله**، الصقه في الـ Console، واضغط **Enter**.

هيلف على كل صفحات الجدول لوحده وينزّل ملف `adaby-requests.csv`.
البيانات كمان بتتحفظ في `window.__MEHWAR__` لو عايز تتفرج عليها في الـ Console.

## الطريقة التانية: بايثون

```bash
pip install -r requirements.txt

# باليوزر والباسورد
python3 collect.py --user اليوزر --password الباسورد -o adaby.csv

# أو بالكوكيز (لو اللوجين فيه كابتشا أو خطوة زيادة)
python3 collect.py --cookie "ASP.NET_SessionId=xxx; .ASPXAUTH=yyy"

# ملف Excel كمان
python3 collect.py --user اليوزر --password الباسورد --xlsx
```

الأوامر المفيدة:

| الأمر | بيعمل إيه |
|---|---|
| `--all` | يجيب **كل** الطلبات من غير فلترة |
| `--keyword "أدبي"` | يغيّر كلمة الفلترة (تقدر تكررها أكتر من مرة) |
| `--url ...` | صفحة تانية غير Emp.aspx |
| `--xlsx` | يطلع ملف Excel جنب الـ CSV |
| `--dump-html debug/` | يحفظ HTML الصفحات (للتشخيص) |
| `--delay 1` | يبطّأ بين الصفحات عشان مايضغطش على السيرفر |

**الكوكيز بتتجاب إزاي:** F12 → تبويب Network → اضغط على أي طلب →
`Request Headers` → انسخ قيمة `Cookie`.

## شكل الملف الناتج

| م | الاسم | الرقم | أرقام إضافية | الشعبة / النوع | الصفحة |
|---|---|---|---|---|---|
| 1 | محمد أحمد سيد | 01012345678 | | أدبي | 1 |

- الأرقام العربية (٠١٢٣) بتتحوّل لإنجليزي أوتوماتيك.
- `+20` و `0020` بيترجعوا لـ `01…`.
- التواريخ مش بتتحسب أرقام تليفونات.
- المكرر بيتشال (نفس الاسم + نفس الرقم).
- لو الصف فيه أكتر من رقم (الطالب وولي الأمر) الأول يروح لعمود «الرقم» والباقي لـ «أرقام إضافية».

## لو النتيجة طلعت فاضية أو ناقصة

السكريبت بيفلتر على كلمة **أدبي** (وكل أشكال كتابتها). لو عندك مسمّى تاني في الموقع:

- **في المتصفح:** غيّر `keywords` في أول ملف `browser-console.js`.
- **في بايثون:** `--keyword "الاسم زي ما هو مكتوب عندك"`.

عشان تتأكد إن الجدول بيتقرا صح من الأساس:

- **في المتصفح:** خلي `collectAll: true` — هيجيب كل الصفوف.
- **في بايثون:** `python3 collect.py --all`

ولو الأعمدة اتقرت غلط (اسم في مكان رقم مثلاً)، شغّل:

```bash
python3 collect.py --dump-html debug/ --all
```

وابعتلي ملف من مجلد `debug/` وأنا أظبط الأعمدة على شكل الجدول بالظبط.

## ملاحظات

- الاتنين بيتعاملوا مع **ASP.NET WebForms**: بيقروا الـ `__VIEWSTATE` ويعملوا
  `__doPostBack` عشان يلفّوا على كل صفحات الـ GridView.
- الملف بيتكتب بترميز UTF-8 مع BOM عشان العربي يظهر مظبوط في Excel.
- الرقم بيتكتب `="01012345678"` عشان Excel مايبلعش الصفر اللي في الأول.
  لو مش عايز كده استخدم `--no-excel-safe`.
- البيانات دي بيانات شخصية لطلبة — خليها في مكان آمن ومتشاركهاش من غير داعي.
